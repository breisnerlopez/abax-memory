Glosario

  • Smoke test: Prueba superficial que verifica funcionalidades criticas tras un despliegue.
  • Tenant: Cliente aislado en arquitectura multi-tenant con datos y configuracion independientes.
  • Flyway: Herramienta de migracion de base de datos que versiona cambios de esquema SQL.
  • OIDC: OpenID Connect — protocolo de autenticacion sobre OAuth 2.0.
  • HNSW: Algoritmo de indexacion de vectores para busqueda aproximada en Qdrant.
  • RTO: Recovery Time Objective — tiempo maximo aceptable para restaurar un servicio.
