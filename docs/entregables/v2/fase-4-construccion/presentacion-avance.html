Feature destacada

Búsqueda Semántica

  • Semantic Search: Embeddings vectoriales con similitud coseno para búsqueda por significado
  • Hybrid Search: Combina resultados semánticos con keyword matching (BM25) para máxima relevancia
  • Graph Expansion: BFS desde un nodo origen, profundidad configurable, relaciones tipadas
  • Relations API: CRUD completo de relaciones entre memorias con metadatos enriquecidos

Nota: Semantic Search y Graph usan actualmente implementaciones in-memory. El reemplazo por Qdrant y Neo4j está planificado como parte de la reducción de deuda técnica pre-QA.
