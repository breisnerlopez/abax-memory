EP-V21-001 · Precisión del Motor

ADRs Clave: Precisión

ADR-001 Aceptado

Reranker Cross-Encoder con OpenAI gpt-4o-mini

  • Pipeline two-stage: dense top-20 → cross-encoder → top-5
  • Reutiliza ChatLanguageModel existente — sin nueva infraestructura
  • Timeout 2s, degradación graceful a dense-only si no disponible
  • Meta: top-1 accuracy ≥ 0.90, NDCG@10 ≥ 0.85
ADR-002 Aceptado

Aislamiento de Búsqueda Semántica Pura

  • expandGraph default cambia: true → false
  • Cuando false: solo dense + cross-encoder, sin grafo
  • El flag controla exclusivamente la activación del grafo
ADR-003 Aceptado

Expansión de Grafo Multi-Origen

  • Default graphTopK=3 (antes 5)
  • entryPoints explícitos con máxima precedencia
  • Estrategias: single-best, top-k, threshold
  • Recall cross-dominio proyectado: 69.4% → ≥85%
ADR-004 Aceptado

Extracción de Entidades con OpenAI Real

  • POST /extract usa exclusivamente OpenAiLlmService
  • Sin API key → HTTP 503; error OpenAI → HTTP 502; timeout → HTTP 504
  • Nunca degrada a MockLlmService (regex)
EP-V21-002 · Velocidad y Latencia

ADRs Clave: Velocidad

ADR-005 Aceptado

Cache de Grafo con Caffeine

  • Clave: hash(entryPoints + depth + kinds)
  • TTL: 60s · Capacidad: 1,000 entradas · LRU
  • Invalidación por evento CDI en mutaciones de relaciones
  • Cache hit: ~85ms (vs ~320ms sin cache)
ADR-006 Aceptado

Diagnóstico de Latencia Qdrant

  • Fase de diagnóstico (semana 1) antes de mitigar
  • Hipótesis: cold start HNSW, lock contention, network, GC
  • Warm-up queries al iniciar (@Startup)
  • Meta: p95 ≤ 500ms en cold start, steady, escritura concurrente
ADR-007 Aceptado

Cache de Validación JWT

  • Clave: SHA-256 del token · TTL: exp − now
  • Cache hit ratio esperado ≥ 0.90
  • Invalidación por Keycloak Admin Events (logout, revoke)
  • Resiliencia: Keycloak caído + token en cache → request procede
EP-V21-003 · Eficiencia Operativa

ADRs Clave: Eficiencia

ADR-008 Propuesto

Diagnóstico y Resolución del Worker Inactivo

  • Hipótesis: Worker v1 inactivo; v2 no implementado
  • Procesamiento es 100% síncrono en POST /memories
  • Escenario A (probable): eliminar worker
  • Escenario B: reparar conexión a cola de mensajes
ADR-009 Aceptado

Unificación de Colecciones Qdrant

  • De 2 colecciones → 1: abax-memories
  • Script offline pre-deploy con snapshot
  • Verificación pre-migración: SQL para datos huérfanos
  • Eliminar hardcode "abax-memories-v2" del código
ADR-010 Aceptado

graphEntryStrategy Configurable

  • Almacenado en JSONB profiles.config — sin nueva columna
  • Estrategias: single-best, top-k, threshold
  • Resolución en runtime con cache de perfil (TTL 30s)
  • Sobrescribible por request vía header X-Graph-Strategy
EP-V21-004 · API y Developer Experience

ADRs Clave: API / DX

ADR-011 Aceptado

Headers X-Graph-Strategy

  • X-Graph-Strategy: none | single | top-k | threshold
  • X-Graph-K: 1–10 · X-Graph-Threshold: 0.0–1.0
  • Headers (no body) → separación de concerns HTTP
  • Precedencia: entryPoints body > headers > perfil dominio
ADR-012 Aceptado

Unificación de Endpoints

  • Endpoint canónico: POST /search
  • Parámetros: semanticWeight, lexicalWeight, rerank, expandGraph
  • /search/hybrid → deprecado con headers Deprecation: true
  • /search/semantic → se mantiene como shortcut
ADR-013 Aceptado

DELETE /admin/namespaces/{name}

  • Nuevo controller: AdminResourceV2
  • Autorización: rol memory-admin en JWT → sino HTTP 403
  • Transacción atómica PG + Qdrant (con mitigación de fallo parcial)
  • Respuesta: resumen con conteo de recursos eliminados

Decisión Solicitada

¿La arquitectura propuesta es correcta?

Abax-Memory v2.1.0 aplica hardening incremental sobre v2.0.9:

  • Pipeline Two-Stage con cross-encoder (gpt-4o-mini) → top-1 accuracy ≥ 0.90
  • Caches Caffeine (grafo + JWT) → p95 ≤ 500ms con cache hit ratio ≥ 0.90
  • API unificada con parámetros semánticos/léxicos y headers de estrategia
  • 13 ADRs con alternativas evaluadas y criterios ponderados
  • Stack inalterado — ninguna nueva infraestructura. Caffeine es librería Java
  • ~20 días de construcción estimados. 7 riesgos con mitigación documentada
