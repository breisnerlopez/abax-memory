Usuarios Objetivo

Los mismos 5 roles de v2.0.0. El principal beneficiario de v2.1.0 es el Desarrollador Consumidor de la API (Memory Consumer).

RolImpacto de v2.1.0
Memory OperatorMayor precisión (top-1 ≥ 0.90). Menor latencia (p95 ≤ 500ms).
Memory ConsumerPrincipal beneficiario. API unificada, X-Graph-Strategy, DELETE namespace, /extract con OpenAI real.
