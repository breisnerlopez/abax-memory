Glosario

Términos clave

TérminoDefinición
Cross-EncoderModelo de reranking que evalúa pares (query, documento) simultáneamente para calcular relevancia fina.
Graceful DegradationEstrategia donde el sistema sigue funcionando con funcionalidad reducida cuando un componente no está disponible.
Two-Stage PipelineArquitectura en 2 etapas: Stage 1 (dense retrieval rápido) → Stage 2 (cross-encoder preciso).
CaffeineBiblioteca Java de caché en memoria de alto rendimiento (TTL, LRU, métricas).
QdrantBase de datos vectorial open-source para búsqueda semántica por similitud de coseno.
ADRArchitecture Decision Record — documento que registra una decisión arquitectónica con contexto y consecuencias.
CDIContexts and Dependency Injection — framework de inyección de dependencias de Jakarta EE / Quarkus.
