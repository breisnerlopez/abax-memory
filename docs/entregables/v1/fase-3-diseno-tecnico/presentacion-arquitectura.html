PMOA - Plataforma de Memoria Operativa para Agentes Arquitectura logica oficial
Topologia MVP

Dos runtime Quarkus y tres piezas de datos

  • memory-api: contratos REST, validacion, autorizacion, consulta y orquestacion.
  • memory-worker: procesamiento de jobs, indexacion y reconciliacion.
  • PostgreSQL: metadata, estados, auditoria, relaciones basicas y jobs.
  • Qdrant: indice vectorial derivado.
  • Workspace Git + GitHub: operacion Git y PR.
Integraciones externas

Keycloak para OIDC/JWT y GitHub para repositorio, PR y webhooks.

Nota de baseline

Kafka, Neo4j y Redis no aparecen en la topologia MVP porque no forman parte del alcance de construccion aprobado.

PMOA - Plataforma de Memoria Operativa para Agentes Flujos tecnicos principales
Operacion MVP

Tres flujos sostienen el valor operativo

Creacion no critica

API valida, persiste estado inicial en PostgreSQL, confirma commit Git y registra job de indexacion para disponibilidad posterior en Qdrant.

Memoria alta o critica

Se crea branch + Pull Request, la aprobacion humana habilita el cambio de estado y luego la indexacion asincrona.

Busqueda semantica

La API consulta Qdrant para candidatos y PostgreSQL para filtros, estados y metadata antes de responder.

Patron de consistencia

La operacion funcional queda confirmada cuando Git y PostgreSQL completan el minimo requerido. Qdrant se actualiza por consistencia eventual controlada.

PMOA - Plataforma de Memoria Operativa para Agentes Datos y seguridad
Fuentes oficiales

Una fuente de verdad por tipo de dato

  • Markdown + frontmatter: Git/GitHub.
  • Estado operativo y auditoria: PostgreSQL.
  • Embeddings y score vectorial: Qdrant.
  • Relaciones minimas: PostgreSQL + frontmatter.
Concurrencia MVP

La toma de jobs se resuelve con capacidades de PostgreSQL, por ejemplo FOR UPDATE SKIP LOCKED o equivalente.

Controles obligatorios

OIDC con Keycloak · JWT validado · RBAC por roles · Idempotency-Key en POST criticos · validacion estricta de payload y frontmatter · TLS 1.2+ · secretos fuera del repositorio.

Regla critica

Una memoria de criticidad alta o critica no puede publicarse sin evidencia de aprobacion por PR.
