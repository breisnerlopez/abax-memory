Contenido principal

Usar este layout para explicar contexto, decisiones, análisis funcional, conclusiones o mensajes ejecutivos con apoyo visual mínimo y alta claridad.

  • Jerarquía tipográfica clara y contraste apto para lectura ejecutiva.
  • Bloques destacados para mensajes clave, riesgos o definiciones.
  • Espaciado consistente basado en variables CSS reutilizables.
Destacado

Este template debe reutilizarse sin incorporar librerías externas, frameworks visuales ni estilos ad hoc por presentación.

Dos columnas

Adecuado para comparar escenarios AS-IS / TO-BE, alcance / fuera de alcance, beneficios / riesgos o decisión / impacto.

  • Columna principal para narrativa o análisis.
  • Columna secundaria para soporte, datos o alertas.
  • Balance visual limpio y profesional.
Tarjeta de apoyo

Ideal para supuestos validados, decisiones solicitadas o dependencias del entregable.

Bloque de riesgo

Evitar slides saturados, colores estridentes o componentes inconsistentes entre fases.
